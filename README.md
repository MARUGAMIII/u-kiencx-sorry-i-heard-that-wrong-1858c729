**"Sorry, I Heard That Wrong"** — one line: the apology a smart speaker gives its owner after mishearing them. A single Python program (stdlib only, deterministic) writes the line to `/output/entry.txt`.

The line: a speaker that mishears "call Mom" as "call the morgue" — Mom is on hold, and the speaker, unfazed, offers to leave a message.

## Run it

```sh
python3 main.py
```
